# Polymer & Industrial Website (Vercel Static Version)

This project is a static HTML/CSS/JavaScript conversion of the original PHP starter website, suitable for deployment on Vercel.

## Deploy with GitHub + Vercel
1. Create a new GitHub repository.
2. Upload all files and folders from this project to the repository root.
3. In Vercel, choose **Add New → Project** and import that GitHub repository.
4. Keep Framework Preset as **Other**. Leave Build Command and Output Directory empty (or set Output Directory to `.`).
5. Click **Deploy**.

## Before publishing
- Replace `YOUR COMPANY NAME`, phone, email, WhatsApp number and address placeholders in the HTML files.
- Replace sample Unsplash images with company-owned/licensed product and factory images.
- Verify the product range and all technical claims against the actual company catalogue.
- The inquiry form currently opens the visitor's email application. For direct web submissions, connect Formspree or implement a Vercel serverless function with an email provider.
